# 把底色扩进线稿下方，收掉上色白边

2026-11-24 · 查阅 Clip Studio Paint 和 Krita 的填充文档，试了同一只陶壶的三种底色范围。

数字上色时，带抗锯齿的线条边缘有一圈半透明像素。填色若提前停在里面，底纸会从线条和色块之间透出来，像一条额外的亮边。把底色放在单独的图层上，往线稿下面多铺一点，可以保留原本平滑的线条，同时盖掉空隙。

Clip Studio Paint 的官方示范使用区域扩张（Area scaling），并用 To darkest pixel 让色块扩到线条较深的位置。Krita 的填充工具也有 Grow Selection，可选在线条开始变浅或透明时停止扩张，在一张稿里处理不同粗细的轮廓。 [Clip Studio Paint · 填充基础](https://tips.clip-studio.com/en-us/articles/590) · [Clip Studio Paint · 高级填充设置](https://help.clip-studio.com/en-us/manual_en/420_fill/Advanced_Fill.htm) · [Krita · Fill Tool](https://docs.krita.org/en/reference_manual/tools/fill.html)

## 在最细的轮廓处验收

1. 用线稿作填色参照，在下方新建底色层。先填一块，再关闭和打开底色预览，找到原稿里确实应该盖住的细缝。
2. 从小范围扩起。让底色盖住线缘下方露出来的纸色，再看外缘和细线是否冒出色块。笔压变化大时，可以用按最深或最不透明像素停止扩张的选项，再检查尖角和内孔。
3. 放大看把手、袖口或手指之间容易漏色的部位，最后回到实际发布尺寸看一遍。修生成图的底色接缝时，可在局部重建色块蒙版，保留上层线稿，用同样的方法比较前后。 [局部修改的蒙版与差值检查](local-edit-mask-and-difference.md)

## 陶壶底色的三次试填

三图使用同一份线稿、形状和色层，成品各宽 390 像素。用已知的陶壶形状做参照，把最初的填色轮廓向内收 3 个成品像素。然后从这份填色分别扩张 0、3、6 个成品像素。画稿按成品的 3 倍分辨率合成，再缩小回查。

在缩图的蒙版上，统计形状内侧中线稿与底色均接近透明的像素，以及形状外侧中线稿接近透明、底色覆盖量至少为 128/255 的像素。内外分别取形状覆盖量至少 230/255 和不超过 25/255 的地方，线稿或底色不超过 25/255 视作接近透明。

| 从原填色往外扩 | 线内空隙 | 线外溢色 |
| ---: | ---: | ---: |
| 0 px | 372 px | 0 px |
| 3 px | 0 px | 0 px |
| 6 px | 0 px | 696 px |

在这张小样上，扩 3 像素盖住了把手内圈和壶身边的白缝。扩 6 像素后，把手的内外缘都能看到薄薄一圈壶色。选扩张量时，可以从稿子里最细的一条线和最窄的一个内孔先试。
