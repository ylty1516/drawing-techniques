# 浅色拟声字跨亮暗背景时加外描边

2026-11-24 · 查阅嵌字教程和对比度说明，并用门锁的「咔嗒」对照了几种外描边宽度。

浅色拟声字放在暗门上很清楚，伸到门边的亮墙时，几个笔画可能融进墙色。可以让字的填色先定下来，在外面加一圈来自画面暗部的深色，再缩到实际阅读宽度检查。描边较粗时，也要看字与字之间的缝，以及笔画围起来的空隙。

Liz Staley 在嵌字示范中把描边加在拟声词图层的外面，并分别调整颜色和粗细。Clip Studio Paint 的漫画指南也演示了用图层属性给拟声词加边。W3C 的对比度技巧提到，文字跨过明暗变化的背景时，可以在周围加一圈提供局部对比的边。 [Liz Staley 的拟声词示范](https://tips.clip-studio.com/en-us/articles/3221) · [Clip Studio Paint 的拟声字加边指南](https://www.clip-studio.com/site/gd_en/csp/startupguide/csp_startup/CSPaint_04/Chapter04_10_1.htm) · [W3C G18 的文字对比度测法](https://www.w3.org/WAI/WCAG21/Techniques/general/G18)

## 先看哪些笔画丢了

1. 先在成品尺寸上看原字，找到最容易和底图并在一起的笔画。门锁响时，把接触的零件和拟声字分开留位置。 [用接触点定拟声词位置](place-sound-effects-near-contact.md)
2. 在字层下加外描边，保留原有的笔画和填色。可以从附近暗部取色，再把描边压深一档，先试较窄的一圈。
3. 导出成品大小再看。若亮处还有笔画丢失，可以逐档加宽。若描边把字间缝堵住，先试加一点字距、换成内孔更敞的字形，或把字挪进一块色调较连贯的画面区域。

## 同一个「咔嗒」的对照

门、文字位置和填色相同。字用微软雅黑粗体，折算到 390 像素宽的图上约为 65 像素，填色为 `#f4f0e4`，描边为 `#293632`。在成品图上，以原填字蒙版选出至少 244/255 不透明的笔画像素，分别沿上下左右至多找 3 像素，配对最近的不透明度不超过 11/255 的字外像素。两稿在同一批坐标取合成后的颜色，用相对亮度算对比度。表中的 4.5:1 是这次小样的比较线。

| 缩放后的描边宽度 | 达到比较线的抽样数 | 其中，亮墙一侧达线数 |
| ---: | ---: | ---: |
| 0 px | 1,305 / 1,984 | 0 / 373 |
| 约 1.33 px | 1,770 / 1,984 | 165 / 373 |
| 2 px | 1,984 / 1,984 | 373 / 373 |
| 3 px | 1,984 / 1,984 | 373 / 373 |

2 像素的描边让亮墙上的「咔」字轮廓连起来。继续加到 3 像素时，达线的抽样数保持相同。逐处检查 2 像素版时，原有五块可透出底图的封闭小空隙里，有三块找不到接近透明的底图露出点了。这里把字层不透明度不超过 32/255 算作露出。这几处仍保留浅色字与深色内侧的边界。遇到笔画更密的字，可以同时检查字形内部和最亮的背景，再决定边线留多宽。
