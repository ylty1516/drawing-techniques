# 用成品尺寸检查中文气泡的字号和断行

2026-11-23 · 查阅资料并试排同一句中文对白

气泡在原画上排得下，缩到手机宽度后也要能读。把最终的图像展示宽度定下来，再一起调整字号、行宽和断点。逗号、句号随前面的字读，开引号与后面的词放在同一行。

W3C 的《中文排版需求》列出行首行尾的标点安排。Clip Studio Paint 的漫画教程说明了气泡里可单独调整文字大小和位置。用网页排字时，也可以用 CSS 的 `line-break` 调整自动断行，再检查实际逐行结果。 [中文排版需求](https://www.w3.org/TR/clreq/) · [Clip Studio Paint 的气泡与对白教程](https://tips.clip-studio.com/en-us/articles/502) · [W3C 的 CSS 断行规则](https://www.w3.org/TR/css-text-3/)

## 先在展示尺寸看字号，再排气泡

1. 从实际阅读界面取得漫画图像的展示宽度。等比缩放时，展示字号约等于画稿字号乘以展示宽度与画稿宽度的比值。固定正文的字号和行距后，用这组规格把真实对白排一次。
2. 按语意与标点找断点。把逗号、句号和收引号留在前文旁边。用网页合成时，给文字标明简体中文，可先试 `line-break: strict`，再检查语言、字体与实际换行。
3. 如果严格断行多出很短的尾行，先看气泡附近有没有余地稍加行宽，或调整分行。需要长一点的对白时，也可以让同一角色分两个气泡说。缩到手机大小时再检查气泡是否压脸、字和边线挨得是否太近，以及尾巴仍指向说话的人。

## 同一句对白的四种试排

以 768 像素宽的画稿排「我想和你走到街角去吧，回头路上再慢慢说。」四种版本都缩到 390 像素宽看。用斜线表示浏览器实际换行。

| 试排 | 画稿字号 / 行宽 | 展示字号 | 实际换行 |
| --- | --- | ---: | --- |
| A，任意位置断行 | 32 / 320 px | 16.3 px | 我想和你走到街角去吧 / ，回头路上再慢慢说。 |
| B，严格断行 | 32 / 320 px | 16.3 px | 我想和你走到街角去 / 吧，回头路上再慢慢 / 说。 |
| C，稍加行宽 | 32 / 352 px | 16.3 px | 我想和你走到街角去吧， / 回头路上再慢慢说。 |
| D，缩小字号 | 23 / 320 px | 11.7 px | 我想和你走到街角去吧，回头 / 路上再慢慢说。 |

这张小稿里，B 解决了逗号在行首的问题，第三行仍只剩一个字和句号。C 把气泡多用了一点画面宽度，保住 16.3 像素展示字号，换行也刚好落在逗号后。D 让对白回到两行，展示字号降到 11.7 像素。复做时先放进自己的字体、文句和画面，再用同样的对照确定行宽。
