# 用雾色和明暗差画出近中远景

2026-11-23 · 查阅资料并试画同一组立柱的冷雾和暖雾

远处的立柱还可以保留大轮廓。让它受光和背光的两块颜色都更接近环境雾色，内部的明暗差就会缩小。近处的立柱保留足够反差，以便看清柱子的体积和前后位置。

Narasimhan 和 Nayar 的大气视觉研究用两部分解释雾中的外观变化。来自物体的光沿途减弱，空气又把一部分环境光散射进视线。James Gurney 的作画笔记展示了远处也可以随当时的环境光呈暖色。借到漫画里，可以先定雾的颜色，再按远近调整每层物体靠近雾色的程度。 [大气视觉研究](https://cave.cs.columbia.edu/old/publications/pdfs/Narasimhan_IJCV02.pdf) · [James Gurney 的远景暖色示例](https://gurneyjourney.blogspot.com/2011/05/warm-colors-in-distance.html)

## 先摆出三层色块

1. 定空间的近、中、远层和雾里最亮的大面。给同一束光照到的雾选一种基调。雨后天光下可以试蓝灰，夕阳附近可以试暖灰。
2. 在每层同时选亮面和暗面。较远时让两面都向雾色靠近。先缩小明暗差，再决定留下哪些轮廓线。要保留远处的关键标志，可把轮廓用成一块完整的形状。
3. 给生成工具同一张深度小稿和一组雾色色样。写明近景哪个边缘要清楚，中景保留哪些转折，远景以哪几块低反差的大形为主。
4. 缩到成品宽度，先看剪影能否读出远近，再转成灰度看明暗差。如果角色脚下、衣摆和近处道具也被雾吞掉，可以缩小近景受雾的范围。 [三阶灰度小稿](three-value-thumbnails.md)

## 同一组立柱的两种雾色

两稿都用同样的柱子颜色和摆位。左稿的雾色为蓝灰 `#adbec5`，右稿为暖灰 `#c8ad90`。计算时在线性光空间以 `t × 物体色 + (1 − t) × 雾色` 混合，`t` 是试画中由近到远逐步减小的保留比例。

| 景深 | 物体色保留比例 | 两个柱面之间的相对亮度差 |
| --- | ---: | ---: |
| 近景 | 0.90 | 0.139 |
| 中景 | 0.55 | 0.085 |
| 远景 | 0.18 | 0.028 |

亮度差按混合后的线性颜色计算。两稿缩到 130 px 宽时，近柱的两个面仍分得开，最远的柱面接近同一片雾色。冷雾和暖雾都保留了这组强弱关系。表中的比例来自这组示意图，换光源、雾的分布或物件位置时，可以重新做小稿取样。
