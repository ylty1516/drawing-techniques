# 给跨格道具记下位置和状态

2026-11-23 · 查阅资料并试做同一组取伞分镜

人物从伞架抽走红伞。画下一格时，除了他手里的伞，还要记得画出伞架空下来的位置。拿走、交给别人、弄湿和破损都可以记成故事动作前后的两种状态。尤其是按镜头分别出图时，状态表能用来核对看得见的前因后果。

ScreenSkills 的场记工作说明建议按故事顺序记录人物动作、服装和道具，并留照片及文字供后续镜头核对。Magliano 与 Zacks 的电影研究发现，在他们分析的影片里，动作中断比单纯的时空切换更常让观众划分新事件。把这两点借到条漫里，可以先排进出格时的道具状态，再用相邻画面确认变化接得上。 [ScreenSkills 的场记工作说明](https://www.screenskills.com/job-profiles/browse/film-and-tv-drama/technical/script-supervisor-film-and-tv-drama) · [Magliano 与 Zacks 的研究原文](https://bpb-us-e2.wpmucdn.com/sites.wustl.edu/dist/e/952/files/2017/09/maglianoandzacks2011-22vhbrv.pdf)

## 先记动作，再配出图参照

1. 给影响剧情的道具定一个稳定特征。例子里只有一把砖红色伞，缠着一条米白布带。同款道具成排放置时，额外记下原先的槽位或靠着的物体。
2. 每格记录动作前后的所在位置、持有人和可见变化。道具出了画框时，照样记下它由谁带着。需要省略中间动作时，让后格保留抓握、空位或物件变化等线索，方便读者推断前一动作。
3. 把原位、转移和新位置画成三格构图小稿。给生成工具固定场景参照和当前格需要的状态，写明空出来的槽位。跨格使用画稿作参考时，把前一格已经消耗或取走的物件标在状态表里。
4. 连读图稿后再排字。先看取出前后的槽位，再追道具的颜色、布带和抓握。局部画错时，可以优先修道具或空位。 [局部重绘的检查办法](local-edit-mask-and-difference.md)

## 取伞的状态表

| 格 | 左侧伞架 | 红伞及其标记 |
| --- | --- | --- |
| 1，伸手前 | 黄伞、红伞、灰伞 | 在中槽，布带系在伞布上 |
| 2，提起 | 黄伞、空位、灰伞 | 被手握住钩柄，伞尖已离开架沿 |
| 3，出门 | 黄伞、空位、灰伞 | 由同一人带出，布带仍在 |

## 两次生成的回查

用同一段文字说明各出一张三格稿。A 只给文字，B 另附一张自画的状态小稿，把黄伞、红伞和灰伞的槽位及出门动作画成简化色块。

| 核对项 | A，仅文字 | B，附状态小稿 |
| --- | --- | --- |
| 伞架数量 | 第一格三把，末格剩黄伞和灰伞 | 第一格三把，末格剩黄伞和灰伞 |
| 米白布带 | 三格都能在红伞上找到 | 三格都能在红伞上找到 |
| 中格的提离动作 | 伞尖叠过架沿，仍落在两条架线的下方 | 伞尖接近架沿上缘，中槽大部分露出 |

两组都画出了红伞转移和架子空下来的结果。放大看中格，两张图的伞尖都还没有和架沿拉开清楚的空隙。要强调已经完全提离，可以再向上调整伞尖，留一段缩小后仍看得见的空白。这是每个条件各一次的出图记录。比较参考图对稳定性的影响，还需要固定图幅并重复生成。
