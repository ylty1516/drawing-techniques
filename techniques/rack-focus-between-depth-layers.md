# 同一机位里怎样从近物转焦到远处

2026-11-24 · 查阅资料并试做钥匙到门口的转焦

镜头先让桌上的钥匙清楚，随后让门口的人清楚起来。两处事物一直留在同一画面，清楚的轮廓随故事重点改变。漫画可以用相邻两格画出这两个状态，动画可以把中间的模糊变化连起来。

俄克拉荷马州立大学的影视教材用同一镜头里前景和背景交换清晰度说明转焦。Adobe 的 Premiere 示范给两个区域设方向相反的模糊关键帧。Jacobs、Baek 与 Levoy 的焦点堆栈研究也提醒，合成不同深度的清晰区域时要检查交界周围的光晕。 [影视教材的转焦示例](https://open.library.okstate.edu/introfilmtv/part/cinematography/) · [Adobe 的转焦合成示范](https://helpx.adobe.com/ee/premiere-pro/how-to/focus-pull-effect.html) · [Stanford 的景深合成研究](https://graphics.stanford.edu/papers/focalstack/)

## 让两处清晰度按剧情先后交换

1. 在定好的构图里选两个不同深度的重点，例如近处钥匙与远处门边的人。先画两处都清楚的底稿，并确认两者在缩图里各有容易辨认的轮廓。让起点和终点分别对应一个叙事动作，例如注意到钥匙、听见门口响动。
2. 分出桌面与钥匙的前景层，以及门口和人物的远景层。远景尽量画到会被前景遮住的范围里，方便焦外轮廓变软后仍能露出正确的背景颜色。
3. 首先保留近处关键边，把远层放软。下一格把远处的关键边提清，放软近层。动画时，让两个层的模糊关键帧向相反方向变化，并在两端各留出能认清物件的一拍。 [硬边和软边的处理](edge-control-for-focus.md)
4. 用生成工具时可沿同一份构图先做清楚的分层画稿，再合成转焦。回看时对照桌角、门框和灯的位置，放大检查前景边上有没有突出的色边。转焦前后，各看一次钥匙和人物的轮廓是否仍处在原来的位置。

## 两层小样

两格各宽 390 px、高 220 px。场景、光色和物件轮廓共用，A 的近层和远层分别使用 0.35 px 与 4.20 px 的高斯模糊半径，B 互换这两个值。在前景合成时，让预乘透明度的颜色和遮罩一起模糊，再盖回完整的远景。

对钥匙和门口人物分别固定一个取样区域。量每个区域中横向和纵向相邻像素的 RGB 绝对差，再对两个方向的每通道平均值求均值。数值越高，表示这个小样里该区域保留了更强的像素边缘。

| 画面状态 | 钥匙区域 | 门口人物区域 |
| --- | ---: | ---: |
| A，清晰度留在近层 | 6.25 级 | 1.67 级 |
| B，清晰度移到远层 | 0.99 级 | 3.77 级 |

同一块钥匙区域的边缘差下降时，门口人物区域的边缘差上升。近处还看得出钥匙的大形，门口的头部和肩线已经清楚。小样用两层高斯模糊近似焦外变化。换场景时，可以先比较两个区域的清晰度，再用剧情节奏决定停留和过渡。
