# 画开门分镜时，先锁住铰链轴

2026-11-25 · 查阅转轴和铰链资料，给同一扇平开门做了两组开门分镜。

连续画三格门从关着到打开，先找门框上的铰链轴。门扇的长边沿着这条轴转，把手随着门扇走。给每一格保留门框上的一处参照，读者就能看出门开了多大。

Autodesk Maya 的文档说明，旋转围绕所选的枢轴进行，并演示怎样把默认在物体中心的枢轴移到指定位置。Unity 的铰链组件也用 Anchor 指定铰链位置，用 Axis 指定转轴，并将门作为适用例子。借到分镜里，可以用俯视稿锁住门框上的轴，再把门扇和门把手沿同一个角度画出来。 [Autodesk Maya · Change the pivot point](https://help.autodesk.com/cloudhelp/2024/ENU/Maya-Basics/files/GUID-150B390E-840B-4FE3-B8E9-8DEBCE7CEC97.htm) · [Unity · Hinge Joint](https://docs.unity3d.com/Manual/class-HingeJoint.html)

## 从门框定转动的位置

1. 在侧边标出上、下两颗铰链，用竖线连起来。俯视图中，先把这条轴标为一点，再画合拢时门扇的方向。
2. 绕这个点画三个开度。门扇宽度在俯视稿里保持一致，把手随着门扇转，跟轴的距离一致。把门扇的两个端点投回分镜的透视，门在画面里的宽度会随角度改变。 [从动作相邻阶段接上特写](match-action-into-close-ups.md)
3. 连看时先追门轴和门框的接点，再看把手。用生成工具分格时，带同一套门框和铰链位置参照。换机位后，可以在新格从墙面与门框重新推出原来的轴，用空间位置校对。 [在跨格画面记录道具状态](prop-state-across-panels.md)

## 同一扇门的对照

门扇宽 0.90 米、高 2.00 米。两版共用一个正交机位和同一门框，画关门、开 35°、开 70° 三个位置。A 绕门扇中央的竖轴转，B 绕门框铰链转。标记距地 0.42 米的同一个门扇铰链点，量它离门框上对应的点的空间距离和画面距离。

| 门的开度 | A · 空间偏移 | A · 画面偏移 | B · 画面偏移 |
| --- | ---: | ---: | ---: |
| 0° | 0 m | 0 px | 0 px |
| 35° | 0.271 m | 4.7 px | 0 px |
| 70° | 0.516 m | 11.9 px | 0 px |

开到 70° 时，A 的门扇边缘已明显离开门框上的点。B 的铰链边仍与门框相接，把手随着另一边向外转。换门宽、画面比例或机位时，可以用同一处铰链点重新核对。
