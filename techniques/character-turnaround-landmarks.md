# 用转面表固定角色比例和单侧特征

2026-11-23 · 查阅资料、绘制四角度参考并测试两格生成

同一角色转过头，露出的脸面变窄，耳朵、发际和挂在一侧的饰物也会按视角显露或被遮住。把近似的眉鼻下巴比例、头发大形和饰物的位置画进同一张转面表，换镜头时有具体的地方可以对照。

D’source 的动画角色课程用正面、四分之三、侧面和背面记录角色比例。Stan Prokopenko 的头部教程用头骨和侧面形状判断转向，并用眉线到耳朵的角度提示抬头和低头。 [D’source 的角色设定表课程](https://www.dsource.in/course/character-design-animation/model-sheet) · [Proko 的不同角度画头教程](https://www.proko.com/course-lesson/how-to-draw-the-head-from-any-angle/)

## 标好基准线和角色自己的左右

1. 先在同一视平线和中性表情下画正面、常用的四分之三面和侧面。横向拉出眉线、鼻底和下巴三条基准线，对照各稿的高度。遇到俯仰时，先为新镜头重画头部中线和眉耳方向，再沿转过的头部摆五官。
2. 给角色挑几处隔着尺度也认得出的形状。试画用短方下巴、偏低的发梢和浅围巾。正面过渡到四分之三面时，远侧的眼和脸颊可以适当压窄，近侧转折按头骨和颌骨安排。
3. 在参考图上直接写清角色自己的左与右。单侧饰物跟着它附着的位置转动。本例的橙发夹固定在角色左鬓，正面在图中右侧，见左侧脸时可见，见右侧脸时藏到远侧。
4. 给生成工具附上角度参照，并写清当前要画哪个视点、鼻子指向画面哪边、饰物在这格是否可见。成稿与同机位的参照并排，先看头发轮廓与五官，再检查近远侧和饰物。

## 两格生成试验

用同一张四角度参考，为左右两个四分之三面同时提供方向说明。得到的两格都保留了深短发、浅围巾和方下巴，鼻尖分向画面两边。目测，左侧脸那格在近侧鬓部有一枚橙发夹，右侧脸那格的近侧头发为空。

两格在一张 1774 × 887 的图里。取各半画面从图高 14% 到 33% 的头部区域，按橙色阈值取样（R ≥ 150，60 ≤ G ≤ 143，B ≤ 110，且 R−G ≥ 42、G−B ≥ 14），得到 1,185 与 0 个匹配像素。这个取样帮忙确认了明显的橙色色块，发夹的附着位置仍用原尺寸目测。这组结果对应参考图和文字说明一起使用的一次生成。
