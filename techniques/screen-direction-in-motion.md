# 跑动分镜先排动作轴，再检查画面方向

2026-11-23 · 查阅资料并试画同一条跑道的四个机位

同一个人一直跑向终点，换到跑道对面拍，画面里可能变成朝相反的方向跑。短跑、赶车或穿过走廊这类连续动作，可以先画一张俯视小稿，把空间里的路线和每格里的左右方向都定下来。

洛约拉马利蒙特大学的电影制作教材用动作轴解释机位与画面方向，还示范了从轴线上取景，再建立新方向的方法。澳大利亚电影电视广播学校的教材用同侧机位图说明怎样保持相邻镜头的左右关系。把这两种做法用到单人跑动时，可沿当前这段行进路径画轴。 [LMU 的画面方向教材](https://lmu.pressbooks.pub/filmmaking/chapter/screen-direction/) · [AFTRS 教材第 16 页的 180 度规则图解](https://medialab.aftrs.edu.au/wp-content/uploads/2020/11/AFTRS16_Documentary.pdf)

## 按顺序定好路线和机位

1. 在俯视草图上标出起点、终点、角色移动方向和一处读者能认出的路标。转弯时，给转弯前后各画一段轴。角色回头看时，另外标出视线方向。
2. 给同一段直行选轴的同一侧。把远景、中景和特写分别标到图上，同时写下每格从画面哪边进、往哪边出。
3. 有意换到另一侧时，先让读者认出位置。可以画沿轴看向同一个终点的过渡格，也可以拉回宽景，把跑者转弯和路标一起画出来。随后按新机位记录新的左右关系。
4. 给生成工具场地草图、角色参考和本格的入画方向。出图后拿邻格对照跑动箭头、身体姿态、路标和号码牌。需要重画方向时，按新机位调整角色与背景，保住文字和装备原本的朝向。

## 跑道小稿对照

同一条直跑道和同一个终点，四台机位都看向跑者。俯视图令起点到终点为正向，画面向右的横向投影记为正。

| 机位 | 画面横向投影 | 连读时可用的线索 |
| --- | --- | --- |
| A，同侧远景 | +0.287 | 跑者朝右，终点标志在右 |
| B，同侧缩近 | +0.654 | 人物变大，终点仍在右 |
| C，对侧缩近 | −0.679 | 跑者与终点一起换到画面另一向 |
| N，沿轴看 | 0 | 跑者朝纵深移动，终点门架继续交代位置 |

试画中，A 接 B 的横向方向连续。A 直接接 C 时，左右变化容易被读成掉头。N 给出纵深方向和终点的位置，可用来衔接新机位。表中数值只对应这张小稿的机位，复画时可用左右箭头完成同样的检查。
