# 用四点透视贴好纸条和招牌上的字

2026-11-23 · 查阅资料并试排同一张门上通知

门上贴了一张斜着看的通知。先在正视的矩形里排好「今日闭馆」，再让文字跟着纸面的四角一起变换。两行字会按纸面透视倾斜，远侧的字符也能顺着纸的宽窄发生变化。

Adobe Photoshop 的消失点工具用四个角点定义透视平面，再让其中的编辑沿平面缩放与转向。OpenCV 文档的 `getPerspectiveTransform` 同样用四组对应点计算透视变换。做漫画的纸条或门牌时，可以先生成留白道具，再在绘图或合成工具里按四角嵌入准确文字。 [Adobe 的消失点说明](https://helpx.adobe.com/photoshop/desktop/effects-filters/artistic-stylize-filters/vanishing-point-in-photoshop.html) · [OpenCV 的几何变换说明](https://docs.opencv.org/4.13.0/da/d54/group__imgproc__transform.html)

## 先排字，再贴到道具平面

1. 确认文字附着的位置，例如门上那张纸的本身四角。按左上、右上、右下、左下记下顺序。被遮住的一角可以顺着纸边延长估计。遇到折纸或曲面，可以按各个面分别排。
2. 在正视矩形里按原文排字，并留四周边距。保留可改字的原始文字层。把它复制为透明文字图，再把矩形的四角映射到同一张纸的四角。
3. 按纸面明暗压一点文字的对比度。压住纸的胶带、手指和反光可以放在文字上方。气泡和旁白依照阅读顺序另行排版。
4. 缩到成品展示宽度，先找从正面看最小的远端字，再逐字复查原文。句子过长时，可以在正视稿重排，或安排读者看得清的道具特写。 [中文气泡在手机上的字号与断行](chinese-balloon-lettering-at-phone-width.md)

## 门口通知的两种试排

两稿用了同一张纸和两行原文「今日闭馆」「明早九点开放」。纸面四角从左上顺时针取 (90, 53)、(327, 94)、(307, 202)、(72, 247) px。A 把正视文字整体旋转 7°。B 用纸的四角做透视变换。测量的是每行文字在模板上的水平定位线变换后的斜率，角度正值表示向右下倾。

| 排法 | 第一行定位线 | 第二行定位线 |
| --- | ---: | ---: |
| A，整体旋转 | 7.00° | 7.00° |
| B，四角变换 | 2.76° | −5.07° |

四角变换的四个拟合角点误差在这次计算里小于 0.01 px。缩到每稿宽 140 px 后，B 的标题仍可辨认，第二行更细小。画面如果必须读出具体时间，可以再用实际展示尺寸检查副行，必要时提高正视稿字号。

## 有折痕时，左右两片分别贴字

2026-11-25 · 查阅相连透视平面的做法并试贴折纸

Adobe 的消失点工具允许从一个平面的边拉出相连的平面，再按物体调整两面夹角。用在有一道直折痕的纸条上，可以先在展开的矩形里排整句，再把左右两片贴回折好的纸上。 [Adobe 的相连平面说明](https://helpx.adobe.com/photoshop/desktop/effects-filters/artistic-stylize-filters/define-perspective-planes-in-vanishing-point.html)

1. 画或生成一张留白的折纸。标出纸的四个外角和折痕两端，共六点。
2. 在正视纸面上排好文字，按实际折痕位置切成两片。左右各用两个外角和折痕的两个端点做四点变换。同一条展开缝须正好对应同一条画面折边，可以先用一根跨缝细线检查两片的接点。
3. 按原画的光线调节两面的墨色。缩到读者手机上的实际宽度，检查跨折痕的字能否一眼读出来。

### 同一张纸条的试排

两稿共用 390 px 宽的画面、一张 300 × 190 px 的展开稿和同样的四个外角。展开稿的折痕在 x = 150 px，印刷细线在 y = 153 px。下表的 y 从各自画面顶端起算。

| 排法 | 印刷细线在折痕上的落点 |
| --- | ---: |
| 只用四个外角，整张纸一次变换 | 156.1 px |
| 同一起稿沿折痕分开，左右各做一次四点变换 | 169.4 px |

在这张试样里，整张贴会把细线到达折痕的位置往上提 13.2 px。分片后，细线随两片纸各自倾斜，在折痕处接上。两侧变换在折痕上抽查的 71 个位置均与纸面投影重合。
