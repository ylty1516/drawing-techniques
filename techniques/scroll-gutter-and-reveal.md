# 用手机视口校准条漫的格距和揭示位置

2026-11-23 · 查阅资料并试读同一段三格条漫

条漫里，前一格停一下，读者滑动后再看到信封或表情，悬念就多一个拍子。起稿时同时检查两处位置。一个是下一格的顶部，另一个是道具、脸或关键台词最先露出的地方。

Art Rocket 的竖向条漫教程用格间空间安排停顿和转场。Clip Studio Paint 的手机可视区域预览可以在画布上检查当前一屏显示到哪里。 [Art Rocket 的竖向条漫布局教程](https://www.clipstudio.net/how-to-draw/archives/157055) · [Clip Studio Paint 的条漫可视区域预览](https://tips.clip-studio.com/en-us/articles/4001)

## 先排停顿，再用手机宽度试读

1. 指明这段的揭示内容。例如，第一格交代门，第二格让脚步停下，第三格才让地上的信封出现。给同一个连续动作保留紧凑的格距，把更长的空白用在停顿点。
2. 在平台预览或等宽的滚动页面画出当前可视区，记下第 3 格顶部与信封上沿到屏顶的距离。若重点是藏住信封，先看信封的位置。若整个新镜头都要晚一点出现，再用第 3 格顶部判断。
3. 调整格距，也可以在下一格里先画一段门板或地面，把角色的反应和道具排得更靠下。用两种手机可视高度再试一遍，确认关键内容和它的对白按预定顺序出现。

## 门下信封试读

三格原画宽 358 像素，高度依次为 240、245、240。页面顶留 24 像素，左右各留 16 像素。前两格之间固定留 26 像素，只调第二格到第三格之间的距离。宽屏让三格等比放大。下表的格距和可见高度均取自浏览器的 CSS 像素。

| 手机可视区 | 第二格后的格距 | 第 3 格顶部距屏顶 | 第 3 格首屏可见高度 | 信封所在高度范围的首屏露出 |
| --- | ---: | ---: | ---: | ---: |
| 390 × 780 | 26 | 561 | 219 | 73 |
| 390 × 780 | 260 | 795 | 0 | 0 |
| 430 × 932 | 260 | 849.2 | 82.8 | 0 |
| 430 × 932 | 365 | 954.2 | 0 | 0 |

在高一些的视口里，260 像素格距已经露出第三格的门板上部，信封仍在屏幕下方。需要把整个第三格延后时，这幅小稿的 365 像素设置达到了目的。复做时用作品实际的画幅和阅读界面测位置，再按该场戏选择留白。
