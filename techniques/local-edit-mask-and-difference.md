# 用蒙版和差值验收局部重绘

2026-11-23 · 查阅资料并试修一个断开的茶杯把手

修道具接缝时，把原图作为底层。如果生成工具给出了一整张候选，先对齐杯身和杯口，再用蒙版只露出修好的接缝及附近的一小段过渡。用差值图检查变动范围，最后放大看接点和轮廓。

Adobe 的生成编辑说明用选区定义要改的位置。Krita 的透明蒙版可以用黑、白和灰控制图层的隐藏、显示和半透明程度。两种做法都能用在局部修稿流程里。 [Adobe 的选区生成编辑说明](https://helpx.adobe.com/photoshop/desktop/make-selections/refine-modify-selections/use-selections-for-generative-editing.html) · [Krita 的透明蒙版手册](https://docs.krita.org/en/reference_manual/layers_and_masks/transparency_masks.html)

## 先框住缺口，再检查贴回去的边

1. 圈出旧轮廓、要补的空间和所有接点。以杯把为例，选区同时覆盖上下两个接头和杯壁旁一小段。杯口、杯底和背景可以留在选区外，作为对齐参照。
2. 生成时描述具体的连接方式和材质，如「杯把两端与杯壁接起来，沿用原来的线宽和釉色」。支持选区输入的工具可以直接使用选区。若得到整张候选，将它放在原图上方，沿几个固定参照点对齐。
3. 编辑蒙版时，让缺口和接点完全露出，过渡留在附近连续的色块中。回到 100% 查看接线、投影和羽化宽度，细直边和文字附近可以缩小过渡宽度。
4. 用相同尺寸和色彩空间的 PNG 做前后对照。把上层切到「差值」可以看到两图的每通道绝对差，黑色对应相同的像素。差值用于检查波及范围，接点的造型和过渡另用放大图检查。 [Adobe 的差值混合模式说明](https://helpx.adobe.com/photoshop/desktop/repair-retouch/adjust-light-tone/blending-mode-descriptions.html)

## 杯把试修观察

试画用一张 1024 × 1536 的原创简图。把原图和修补的文字说明交给模型，得到相同尺寸的整张候选，再用一块 (257 × 236) 像素的局部蒙版贴回。蒙版内侧留约 18 像素做过渡。比较范围为蒙版外的 1,512,212 个像素。

| 输出 | 任一 RGB 通道有差值的像素 | 任一通道差值大于 8 的像素 |
| --- | ---: | ---: |
| 整张模型候选 | 1,510,489 | 15,990 |
| 蒙版合成稿 | 0 | 0 |

候选图在这个案例里补上了两个接点，选区外也出现了许多小色差。合成稿保住了接点，重新读取导出的 PNG 后，蒙版外的 RGB 仍与原图完全一致。复做时可以按画面缩放选区和过渡宽度，用同样的差值检查确认交付范围。
