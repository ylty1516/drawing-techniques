# 用色彩脚本安排强调色出现的时机

2026-11-23 · 查阅资料并试画夜间站台的四格小稿

夜间站台上，人物伸手摸到一盏灯。前两格让站台维持蓝灰，第三格灯亮了，才把暖色落到灯身、手和近处地面。第四格拉回远景，暖色收回到较小的范围。把这四格缩小并排，能在画细节前看出哪一格该变亮、下一格又会剩下多少亮色。

皮克斯的展览资料用色彩脚本说明每场戏的配色和灯光构想。制作设计师 Ralph Eggleston 也用它安排各场戏之间的情绪和色调变化。借到条漫里，可以先按情节选几格，在小稿上定背景基调和强调色出现的顺序。 [皮克斯展览的色彩脚本说明](https://sciencebehindpixar.org/pipeline/story-and-art) · [Ralph Eggleston 的制作设计文章](https://www.productiondesignerscollective.org/how-do-you-define-production-design-for-animation/)

## 先给转折前后各画一张小稿

1. 挑出情节发生变化的几格。写下每格先要看到的东西，再定一组支撑场景的底色和一组用于强调的颜色。画灯点亮时，前格可以先用形状交代灯的位置。
2. 用大色块试出第一次亮起来的位置。沿灯、手和近处地面安排亮色，把离灯更远的墙与窗保留在原有的色调里。换成天色转亮或开门进入室内，也可以先决定哪几个面会最先受光。
3. 画出转折后的下一格。拉远镜头或移开灯时，可以缩小强调色的面积。把转折前后并排看，检查亮色的变化能否随着剧情读出来。
4. 给生成工具提供这一组色彩小稿和角色参照，写清当前格处于哪一步。出图后把成稿缩小，对照强调色最早出现的格子及它落在的位置。再用灰度检查人物、道具与背景是否还有清楚的明暗关系。 [三阶灰度小稿练习](three-value-thumbnails.md)

## 夜间站台的试画

每格宽 264 px。面积统计使用小稿里预先选定的五种暖色色值，涵盖灯面高光、手上的暖边和地面受光色。

| 格 | 画面的主要变化 | 暖色色块占整格面积 |
| --- | --- | --- |
| 1，站台远景 | 蓝灰墙面和未亮的灯 | 0.0% |
| 2，伸手特写 | 手与灯身仍用冷灰色 | 0.0% |
| 3，灯亮 | 暖色集中在灯、手和近地面 | 16.9% |
| 4，拉回远景 | 暖色留在灯边和脚边一小片 | 2.6% |

缩到每格 104 px 宽后，第三格的变化仍容易辨认。转成灰度也能看见同一处变亮。这组试画同时改变了冷暖和明度，百分比记录的是这组构图怎样分配暖色。换场景时，可以先复做由小到大、再收回的色块变化，再按情节选面积。
